### Added

- DEBUG_INFO=1 builds cardano-node from source with DWARF debug info for perf, in images tagged -dbg1
- CARDANO_NODE_RTS_OPTS passes extra RTS options to cardano-node, e.g. "-hT -i60" for a heap census

### Changed

- Source builds use -j4 for the packages on the serial tail of the dependency graph
- download_profiling.sh also collects .hp and .eventlog files
- Ledger snapshots are written 5-10 min after the request, the 11.1 default, instead of the 11.2 default of 5 min - 6 h (LEDGER_SNAPSHOT_MIN_DELAY/MAX_DELAY)

### Fixed

- Disable per-build provenance attestations, which made make build rebuild every image
- Set a UTF-8 locale in source builds so Template Haskell can read non-ASCII files
